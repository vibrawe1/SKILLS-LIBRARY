# Skill Library Validation Cases

1. Every registry skill path exists.
2. Every SKILL.md has YAML frontmatter with name and description.
3. Directory name matches frontmatter name.
4. Every SKILL.md is below 500 lines.
5. Every referenced companion file exists.
6. Every internal skill dependency resolves in the registry.
7. External capabilities are marked as available, runtime-dependent, or configuration-required.
8. External writes remain approval-gated.
9. Provenance is retained for imported skills.
