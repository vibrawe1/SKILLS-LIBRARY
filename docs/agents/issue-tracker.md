# Issue tracker

This repository uses the local Markdown tracker.

Issues and specs live under:

- .scratch/<feature-slug>/spec.md
- .scratch/<feature-slug>/issues/NN-<slug>.md

Wayfinder map:

- .scratch/<effort>/map.md
- .scratch/<effort>/issues/NN-<slug>.md

A ticket has:

- Type: research | prototype | grilling | task
- Status: claimed | resolved
- optional Blocked by: NN, NN

The local tracker is the canonical tracker for this repository. Do not create GitHub issues for normal skill-library planning unless the user explicitly requests an external GitHub issue.

External writes remain approval-gated. Read-back verification is required after any approved write.
