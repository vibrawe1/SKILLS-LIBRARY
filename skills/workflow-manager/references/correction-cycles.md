# Chapter Correction-Cycle Contract

Each chapter has a maximum of three correction cycles.

One cycle consists of:

1. identifying actionable findings;
2. applying an approved correction scope;
3. rerunning the affected audits;
4. recording the result and remaining findings.

After cycle three, if a blocking or repeated finding remains, set the chapter to `BLOCKED` and escalate to the user. Do not silently start cycle four. A user may explicitly authorize a new bounded plan, which must be recorded as a new decision rather than hidden inside the old count.
